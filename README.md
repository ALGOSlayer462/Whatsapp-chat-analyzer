# WhatsApp Chat Analyzer
Streamlit app jo exported WhatsApp chat (.txt) ka analysis karta hai: stats, timelines, heatmap, wordcloud, common words, emoji analysis.

## Run
```
python -m venv venv
venv\Scripts\activate      # Mac/Linux: source venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```
`sample_chat.txt` se test kar sakte ho.
